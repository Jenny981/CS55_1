# 检索与人工审核

每个保留的Final帧与对应路线的全部证据做CLIP视觉相似度检索，不先按Correspondence裁掉范围外证据。

文字辅助仅在视觉前5名且与视觉最高分差不超过0.05的候选中使用。多个不同文字组存在时，通过 `1/visual_rank + 1.25/text_group_rank` 辅助排序；文字共享组只编码一次。这里是排名组合，不是把原始CLIP、结构、文字相似度直接相加。

默认 `range_top1` 是历史配置名，界面称Global Top-1：候选经可选文字重排后，满足最低视觉相似度即可暂定选择。重复连续使用记为提示。strict模式额外检查分差、辅助支持及连续复用，把不确定结果送审核。

结构和相邻候选是辅助诊断，不构成另一个独立全库结构检索承诺。Animatic→Storyboard提供补充关系，不替代两条Final主路线，也不自动否决三角冲突。

每个Final在每条主路线最多保留一个匹配；两条路线可同时存在支持。人工可换候选、标不匹配或待处理，后端重算结果。自动暂定匹配与人工确认分开记录。任一路有已选证据则Final有支持；没有支持但存在不确定路线则待审核；否则为证据不足。

系统不强制单调路径，因此证据index回退仍可观察。高覆盖率不等于高准确率，未匹配也不能直接证明材料缺失。
